# 2026-09-22

## Agent 列表改为按本机实际情况动态加载（不再写死）

起因：老曹卸载了 OpenClaw，但应用里仍列出它。

### 根因
- `src-tauri/src/adapters/mod.rs` 的 registry 是一份写死的 agent 清单，`list_agents` 全量返回，
  卸载后条目依然存在（只是 `exists=false`）。
- 前端还有两处写死的 agent 常量：`McpTable.tsx` 的 `MCP_AGENT_NAMES` / `MCP_WRITABLE_AGENTS`、
  `AgentPage.tsx` 的 `MCP_SOURCE_AGENTS`——都是 `mcp.rs::sources()` 的重复副本。

### 改法
- `AgentAdapter` 新增 `probe_paths: &'static [&'static str]`（相对 $HOME）。新增
  `is_installed()` / `installed_adapters()`，**实时探测**（`symlink_metadata`，不缓存）。
- `list_agents` / `scan_all_skills` / `search_skills` / `usage::all` 一律遍历 `installed_adapters()`；
  删除了已无引用的 `all_adapters()`。`find()` 仍查完整 registry，故挂载等写操作不受影响。
- registry 里 **保留** openclaw 定义（probe = `.openclaw`）：卸载后自动隐藏，将来重装也自动回来，
  不用改代码。这是「动态」而非「手工删」的关键。
- 新增后端命令 `list_mcp_targets`（`mcp.rs::targets()` → `McpTarget{id,name,writable,available}`），
  name 取自 adapters registry，作为前端 MCP agent 名字与可写清单的唯一来源。
- 前端删掉三处写死常量，改用 `useMcpTargets()` + 新增组合 hook `useMcpAgentMeta()`
  （返回 `nameOf(id)` 与 `writableTargets`）。
